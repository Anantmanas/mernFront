# 🚀 ChatRoom — AI Powered MERN Chat Application

![ChatRoom Banner](./assets/banner.png)

> A modern real-time chat application built using the **MERN Stack** with **AI-powered smart replies**, file sharing, authentication, and blazing-fast communication.

---

## ✨ Features

### 💬 Real-Time Messaging
- Instant one-to-one and group messaging
- Live typing indicators
- Online/offline user status
- Real-time updates using Socket.IO

### 🤖 AI Smart Reply Assistant
- AI analyzes ongoing conversation context
- Suggests quick intelligent replies
- Speeds up communication productivity
- Context-aware response generation

### 📁 File Sharing
Upload and share:
- 📄 PDF files
- 🖼️ Images
- 📎 Documents
- 🎥 Media files

### 🔐 Authentication
- JWT Authentication
- Google OAuth Login
- GitHub OAuth Login
- Secure password hashing with bcrypt

### 🎨 Modern UI/UX
- Responsive dark-themed interface
- Smooth animations
- Minimal & clean design
- Mobile-friendly layout

---

# 🛠️ Tech Stack

## Frontend
- React.js
- Tailwind CSS
- Axios
- React Router
- Socket.IO Client

## Backend
- Node.js
- Express.js
- Socket.IO
- JWT Authentication

## Database
- MongoDB
- Mongoose ODM

## AI Integration
- OpenAI API / Gemini API
- Context-based quick reply generation

## File Storage
- Cloudinary / Firebase Storage / AWS S3
